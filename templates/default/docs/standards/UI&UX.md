# UI/UX规范

**使用时机：修改界面、样式、交互前，读取相关规范。**

### 核心约束

- 间距默认采用 4px 基数的既定 Token。
- 颜色引用语义 Token，支持项目规定的主题。
- 同类组件保持尺寸、间距和状态一致。
- 保证键盘可操作、焦点可见、信息不只依赖颜色。
- 验证窄屏、长文本、缩放及深浅色场景。
- 设计例外需说明原因，复用需求应回收到 Token 或公共组件。

这些规范在 React、Vue 中可以共用；框架层主要负责接入主题状态和组件库，CSS 变量与设计 Token 保持同一套定义。

### 1. 设计变量规范（Design Tokens）

规则：设计值集中定义，组件引用变量，避免各自硬编码。

| 层级     | 英文             | 示例（仅供参考）                        | 用途                   |
| -------- | ---------------- | --------------------------------------- | ---------------------- |
| 基础变量 | Primitive Tokens | `--space-4`、`--blue-600`           | 存储原始尺度和色值     |
| 语义变量 | Semantic Tokens  | `--text-primary`、`--surface-page`  | 表达用途，承载主题变化 |
| 组件变量 | Component Tokens | `--button-height`、`--card-padding` | 表达组件特有样式       |

颜色、间距和字体通过 Token 统一管理，是成熟设计系统常见的实现方式。

| 宽度            | 布局策略                           |
| --------------- | ---------------------------------- |
| `< 768px`     | 单栏，导航转抽屉，辅助面板按需打开 |
| `768–1199px` | 导航可折叠，减少并排区域           |
| `≥ 1200px`   | 完整桌面布局                       |
